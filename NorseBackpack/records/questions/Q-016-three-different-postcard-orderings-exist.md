**Decided: no postcards are held back** (supersedes old page PZ-11 — see there and the Postcards tab). All 22 cards, decoys included, are free to hand out through the game.
**Decided: within each trail's own sequence, the decoy's slot is chosen for narrative fit** — wherever it genuinely fits Aunt Liv's travel story for that leg — not a fixed position (e.g. "always last") and not chosen to optimize the map-shape read. Where exactly that puts each of the four decoys is still open, since it depends on writing each decoy's place in her travel story, which hasn't happened yet.
**Canonical numbering is now decided** (Q-017) and, by construction, is the same thing as per-trail order — a card's code already states its trail and its position in it. **Still open, not yet started:** the in-game release/reveal order (old page PC-18) remains a separate question — do not assume the code scheme settles it.
