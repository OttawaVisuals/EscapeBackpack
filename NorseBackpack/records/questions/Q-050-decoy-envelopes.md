Opened 11 Oct 2026 (designer: "we might need a few decoy envelopes, to be decided"). With 13 envelopes loose in the box, players can see how many are left, and the last envelope is obvious by elimination. Decoys hide that.

Open: how many, and what's inside. Options for what a decoy does:

1. **Blank filler:** a sealed envelope with nothing useful (a note from Liv, a plain card). Only hides the count.
2. **Common wrong answers:** label a decoy with the runes a likely wrong code shows on the wheel (for example a misread digit), and put a gentle "Not quite" note from Liv inside. The cypher wheel can do this: every code, right or wrong, shows its own runes, so any chosen wrong code gives a usable label. This needs the likely wrong answers per puzzle, which only playtests show.
3. **Story extras:** a decoy holds a bonus souvenir or fact card, with runes no code reaches. Opening it early does no harm.

Any decoy must not carry runes that a correct code shows (the builder already guarantees the 13 real labels are distinct; decoys would need the same check). Decoys add reset work: they must be resealed too.
