Status on the old page: **Decided, 16 Sept 2026**

**Decided.** Each card's code is its trail's first letter plus its 1-based position in that trail's real stops; each trail's decoy is that letter plus `D`, regardless of where the decoy sits narratively (Q-016). This deliberately collapses "canonical numbering" and "per-trail order" into one code — there is no longer a separate continuous 01–22 sequence running across trail blocks.
**Codes:** Leif — `L1` L'Anse aux Meadows, `L2` Battle Harbour, `L3` Baffin Island, `LD` Brattahlíð (decoy). Rollo — `R1` Châlus, `R2` Rouen, `R3` Bayeux, `R4` Winchester, `R5` Battle, `R6` Roumare Forest, `RD` Walcheren (decoy). Aud — `A1` Dögurðarnes, `A2` Hvammur, `A3` Esjuberg, `AD` Bjarnarhöfn (decoy). Harald — `H1` Oslo, `H2` Staraya Ladoga, `H3` Kyiv, `H4` Hedeby, `H5` Sicily, `H6` Asia Minor, `HD` Constantinople (decoy).
**Done:** every built asset (postcard fronts/backs/illustrations/ImageGen sources, print PDFs, build scripts, and this page's own filenames, gallery headings and trail-grid labels) is renamed to the new codes. `References/README.md` updated to match.
