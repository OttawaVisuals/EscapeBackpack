Status on the old page: **Decided**

**Was:** `Image_Credits.html` had one entry, Postcard L1. Cards L2 and L3 carried their attribution *only* on the cards themselves, as four printed lines each including two full URLs — so the anachronism Q-009 removed from card L1 was still there, and worse, but stripping it would have deleted the project’s only record of those attributions.
**Done, in that order.** `Image_Credits.html` gained matching entries for **Postcard L2** (“Battle Harbour - MacGillivray”, Matt MacGillivray, CC BY 2.0) and **Postcard L3** (“Grinnell Glacier Bergie Bits, Baffin Island”, Gregory “Slobirdr” Smith, CC BY-SA 2.0), each with original work, photographer, source file page, licence, changes and adaptation licence, sourced from `References/README.md`. Only then were the printed credits reduced to one line each, in card L1’s form.
**No URL is now printed on any card back.** Note the licence difference the page records: card L2’s source is CC BY 2.0 with no ShareAlike condition, while 01 and 03 are ShareAlike and their adaptations must be licensed alike.
**Judgement call worth knowing:** the printed line names the source’s licence but not the adaptation’s, and gives no licence URI. For ShareAlike sources that notice now lives only on the credits page, which ships in the repository alongside the PDFs. Reasonable for the medium, and the same choice as card L1 — but it is a choice, not a technicality.
