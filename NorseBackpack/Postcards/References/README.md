# Postcard visual references

## Source policy for future postcards

Search Wikimedia Commons first. Check each file page individually and prefer, in order: public domain or CC0, CC BY, then CC BY-SA. Do not use NoDerivatives material for illustrated adaptations, and avoid NonCommercial licences if the game may ever be sold. Record the title, creator, source URL, licence URL and changes made for every selected image.

## Visual direction

The general travel-poster direction was informed by the [Kootenay National Park poster](https://canadasparks.com/portfolio-item/kootenay-national-park/) from Canada’s Parks Posters. Do not reproduce its artwork, wording, layout, signatures or branding. Reuse only broad traits: simplified screen-print layers, a limited destination palette, paper texture, strong landmark silhouette and clear tourism-poster hierarchy.
