Overview

A practical review of reasoning, difficulty, team flow and production readiness.

Verdict: strong concept; not yet ready for an unattended full run. The main problems are missing instructions, unbuilt physical mechanisms and release logistics. These should be fixed before making the puzzles harder.
2–4players, ages 16+
60–90minute target, not a measured duration
22existing postcards: 18 route stops + 4 decoys
11proposed required puzzle gates

What works

  • Cards repeatedly unlock new meanings: local clue first, route point later.
  • Distinct actions: spotting, matching, light alignment, mapping, weighing, cipher and board planning.
  • The museum tickets give ordinary-looking props a useful role.
  • The final invitation pays off Liv’s opening message.

What must change

  • Finish the physical links in the balance and light puzzles.
  • Fix the extra E-column rune and state the board’s house rules.
  • Assign contents and separate locks to every required gate.
  • Replace the outdated hints and test the four drawn digits blind.

Prevent accidental bypasses and dead ends

  • The Rollo pouch must genuinely require both its locks: one closure/hasp needing both to open, not two independent zippers that expose the same contents.
  • The cryptex contains only a key for a larger board-kit pouch. This is an additional keyed closure, not an extra puzzle. Confirm capacity and keep the key identifiable.
  • The MEAD wallet contains the journal; the 253 sleeve contains H6 and the transition tickets. Both branches are needed for the intended finale.
  • All released cards and maps remain available. Do not lock a needed tool behind the puzzle it solves.
  • Label hint topics and containers by subject (beasts, coin cache, board), with a visible association. Use S/G numbers only for setup; they need not appear in the fiction.
  • The original leg-release order already suggests Leif–Rollo–Aud–Harald. Do not claim the final digit order is unknowable before the bundle; tickets should confirm it. Accept a well-reasoned early guess rather than redesigning the whole game to police it.

Puzzle audit

Confirmed faults, unfinished links, difficulty judgments and retained mechanisms.

Stable review IDs RV-01–RV-19. Existing project IDs are retained beside them. “Blocker” means a complete self-guided run cannot yet be relied on.

RV-01 · Blocker No complete packing and release plan

Evidence: ST-01 / PC-18

What is there now

The current puzzle data still says “Open” for several releases. Its displayed sequence puts the board before the runes while its own description says the reverse. A list of good puzzles is not yet an executable game.

Recommendation / correction

Use the proposed Adventure flow below: every card has a first release, every gate has contents, and two parallel branches have explicit joins. Treat this as a packing proposal, not a claim about the existing bag.

RV-02 · Blocker One lock cannot hold several future answers

Evidence: PZ-03 / comb / PZ-20

What is there now

SOLE, candidate BOOK and MEAD are assigned to the owned four-letter lock. Resetting it between these puzzles requires intervention or exposes future combinations. The user confirms some 3-digit, 4-digit and 4-letter locks, but not quantities or dial alphabets.

Recommendation / correction

Use distinct locks for SOLE and MEAD in the recommended version; park the BOOK gate. Check that each physical dial can spell its assigned word. Inventory before buying. Never depend on a host resetting a lock mid-game.

RV-03 · Blocker RAVEN selects two possible fourth letters

Evidence: PZ-02 / PZ-09

What is there now

The printed Harald grid has a real F at E3 and a decoy L at E7. Both are in E, one of the columns selected by RAVEN. The printed clue therefore permits HRAFN and HRALN; recognizing an Old Norse word is not an adequate rule.

Recommendation / correction

The separate review map moves only the E7 decoy to I7. R, A, V, E and N now each contain one stem. The route geometry and board back are preserved. Physical legibility is still untested.

RV-04 · Blocker The board ticket teaches different rules from the puzzle

Evidence: PZ-01 / PZ-07

What is there now

The ticket explains moving all pieces and capturing. The unique 253 route was computed with every piece except the king fixed and no capture. H1 asks for three moves but never states those restrictions.

Recommendation / correction

Add the supplied “Our three-move challenge” slip, or merge it into H1 later. State fixed pieces, no capture/jumping, exactly three rook moves, any corner, and distances excluding the starting square. The 11×11 fixed-board search independently confirms F6 → H6 → H11 → K11.

RV-05 · Blocker The balance chain is missing two player-facing links

Evidence: PZ-03 / PR-02 / PR-20

What is there now

A3 says to flip the reading, but its PDF has no crossed-out final digit or display sketch. Its source explicitly calls that sketch unbuilt. The coin types and matching cache mark are not specified as a complete produced set. The intended 370.56 g also remains a physical target, not a measurement.

Recommendation / correction

Draft a shared mark for cache and selected coins; add the supplied truncation instruction; calibrate on the actual scale. If retaining two decimals, every acceptable selected-pile reading must truncate to 370.5 (370.50–370.59 g). This is a mathematical acceptance interval, not a tested tolerance. Test tare, units, repeatability, battery and display orientation before using SOLE.

RV-06 · Blocker BOOK has no verified extraction

Evidence: PC-06 / PR-19

What is there now

AD exists, contrary to one stale risk note, but no matched comb tooth layout, alignment stops or exact extracted letters were found. The answer BOOK is still a candidate, not a working prop.

Recommendation / correction

Keep AD in the deck for the final filter. Make the comb an optional exploration until a real-size mask cleanly reveals only B–O–O–K. If it becomes mandatory later, add its own lock and a reliable placement/orientation cue.

RV-07 · Blocker The ruler puzzle has no calibrated answer

Evidence: PZ-14 / PC-15

What is there now

CROSSBOW BOLT, TREATY and SCALE 1 TO 5 identify a method, but the physical ruler, exact endpoints, unit, rounding convention and lock digit count are unresolved. A rescaled print changes the answer. “Tree + tea” also admits several readings.

Recommendation / correction

Retain the three cards and rebuses as an optional discovery in the 60–90-minute version. Do not assign a numeric code. To restore a lock: choose the actual ruler, mark two measurement centres, add a scale check and units/rounding rule, then independently measure the final laminated sheet.

RV-08 · Fix before testing Top-edge action is not discoverable from the messages

Evidence: PC-06 / PC-13

What is there now

L2 and L3 contain no instruction to combine them, reverse one, or use transmitted light. The proof image and top-edge test PDF do not establish reliable viewing through two finished, double-sided cards.

Recommendation / correction

Use the supplied “Two skies” cue for the first playtest. Test actual stock, trimming, ink, light source and laminate. The current 1576 is an intended result; do not call this gate ready until strangers can see it. A sealed rescue answer can keep a prototype running, but is not a production fix.

RV-09 · Fix before testing Aud’s printed wording is weaker than its documented explanation

Evidence: PZ-17

What is there now

The puzzle description says A2 gives a southward direction and a forest cue. The current PDF gives the forest cue only, and says “rivers, fords and gates” while the ticket asks for bridges, fords and gates. The ticket itself is a good six-leg tally with a worked first row.

Recommendation / correction

Proposed A2 replacement: “From the standing stone I went south, along the road beside the forest, to the village at the crossing. I might have to remember how many bridges, fords and gates I crossed.” Validate this against the actual drawn route before reprinting. Preserve the tally 5 / 2 / 1 only if the paper walkthrough agrees.

RV-10 · Fix before testing Final digits are asserted, not geometrically proved

Evidence: PZ-06 / PZ-18

What is there now

The original answer PDFs label the shapes 1, 9, 7, 2. Those labels and the solver’s fixed digit table do not test recognition. Harald is an angular zigzag; Rollo’s loop nearly closes near Rouen/Roumare; Leif’s short opening stroke is small. Aud’s seven has a nearly vertical stem.

Recommendation / correction

Run a blind recognition test with labels hidden, north up and no expected code given. If a shape fails, adjust a schematic inset or route design in a new proposal, then recheck all dependent clues. Do not rely on guessing the year 1972. The review does not silently warp geography or claim these shapes passed.

RV-11 · Blocker for self-guided play The existing hint site is incomplete and stale

Evidence: norse-hints.html

What is there now

Only the opening, beasts, top edge, finale and ending are listed. The finale still tells players to sort interleaved postcard dates, which the current cards do not carry. The top-edge entry exposes design notes rather than a gradual hint.

Recommendation / correction

A separate review hint page now covers all 11 proposed gates, with three hints and an explicitly hidden solution each. Supply a reachable local/hosted URL or printed fallback; a localhost link on the designer’s computer is not automatically usable by players’ phones. Test it without a host.

RV-12 · Fix before testing The journal makes the decoys contradict the story

Evidence: PZ-18 / journal PDF

What is there now

“Every place I actually stopped” excludes four postcards that describe real visits; the Walcheren transition ticket and journal then use one of those visits as an ordering anchor. Literally discarding that card makes the chain harder to follow.

Recommendation / correction

The proposed journal says these are stops selected for the traced routes; other cards remain travel memories. The final-method slip says to exclude them from drawing, but keep them for interpreting the tickets. This preserves LD/RD/AD/HD’s earlier jobs.

RV-13 · Fix before testing Rouen needs a clear extraction and counting convention

Evidence: PZ-15

What is there now

R2 mentions fighting, people, poultry and Inn: these are not four Saxon-column words as the old description claims. The ticket gives coordinates, but neither it nor the card clearly states icon-to-coordinate distances or whether to count endpoints. The 15-row ticket itself is usable; extra vocabulary is not automatically stale.

Recommendation / correction

Accept either member of each matching pair. Use reading order fight → people → poultry → inn, then H6→I6 = 1, F11→F7 = 4, I3→A3 = 8, H9→B9 = 6. The supplied slip states four grid journeys and excludes the starting square. Keep unused cow/forest icons as scenery only after testing for distraction.

RV-14 · Test risk Counting is sound in principle, but the smallest details matter

Evidence: PZ-19

What is there now

At full source resolution R1 shows two bolts (one on the nearer round tower, one at the tall tower’s top), R6 shows three boars among deer, and RD shows five boats. The intended before-911 / 911 / 1199 order gives 5, 6, 2 after doubling boars. Reduced previews conceal some of these details.

Recommendation / correction

Keep this as the accessible parallel task on Rollo. Give players a magnifier and test the printed 5×3.5-inch cards. Add a first hint that specifies the three cards and the history dates; do not make guessed animal silhouettes or external history carry the solve.

RV-15 · Fix before printing Print filenames can deliver an incomplete deck or an answer

Evidence: Print packaging

What is there now

Norse_Postcards_Full_Print.pdf has six pages: three two-sided cards, not the 22-card deck. The four LongEdge sheet PDFs contain 4 + 4 + 4 + 2 card backs: only 14 cards. Aud_Ticket_Print.pdf includes a third page containing ANSWER 5 2 1. The separate Aud Letter version has two player pages.

Recommendation / correction

Use all 22 individual current card PDFs linked in the Gallery. Neither the misleading “Full” PDF nor the existing four-sheet set is a complete deck. The review folder includes Aud_Ticket_PLAYER_ONLY.pdf. Keep all *_ANSWER PDFs and review notes out of the game.

RV-16 · Documentation Competing versions obscure what is actually built

Evidence: AGENTS / system / final-riddle / guide

What is there now

The shared guide says 18 cards, while the produced deck is 18 route cards plus four decoys. Tabs mix interleaved dates with the newer blocked journey, and old 7×7 board, 467/531 Aud codes and unbuilt-map claims remain next to current material. Marks and all 22 card backs are now built.

Recommendation / correction

This review works from the current 22-card print set and labels that assumption. It preserves the original rather than silently adopting a new invariant. Current facts, proposed changes, open decisions and old source material are separated here. Approval is still needed to reconcile the 18-card guide with production.

RV-17 · Production gap The invitation is a concept rather than a packed reward

Evidence: ST-05

What is there now

The indexed production PDFs contain no final personal letter/plane-ticket reward. H6 already promises one more puzzle, so giving it too early creates a false ending.

Recommendation / correction

Release H6 only when the last required Harald puzzle is complete. Write the invitation and fictional ticket after the dig/reward choice; do not invent a booked flight, date or excavation site. The final container should contain a satisfying personal ending, not another unexplained task.

RV-18 · Test risk Difficulty is uneven rather than uniformly hard

Evidence: PZ-20 / whole game

What is there now

MEAD may be guessed from HONEY alone by an experienced player, while FERMENTED from sugar + bubbles + time is interpretive. Meanwhile the board reconstruction, Aud map and final ordering each involve several transformations. These are designer judgments, not observed solve times.

Recommendation / correction

Let MEAD be a shorter confidence-building parallel win. Accept fermentation/fermenting as intermediate readings; the four-letter lock validates the drink. Do not require exact vocabulary before attempting the lock. Put clearer instructions around physical operations, preserving the deductions themselves.

RV-19 · Test risk The finale model knows more than the printed clues

Evidence: Tools/final_riddle_clues.py

What is there now

The enumerator assumes the real-card sets, leg assignment, leg order and intended digit per route. It also encodes a direct Bayeux→Winchester adjacency while the current journal only implies before/after. It is useful evidence about its model, not an end-to-end player simulation.

Recommendation / correction

Playtest & hints

What must be proved before calling the backpack ready.

First test goal: distinguish “could not infer the answer” from “could not read or operate the prop.” Do not use completion alone as proof that every gate is fair.

For two players

Let each player own one Rollo task and one Harald branch, then compare. They can alternate reading/navigation on Aud. Use two maps at a time in the finale; keep the journal available to both. No simultaneous timing or dexterity requirement should demand a third person.

For four players

Use two pairs during Rollo and Harald. Rotate reader, mapper, counter and lock-handler so one confident solver does not monopolize the bag. Four maps give the finale its best team moment; bring the group together to justify the final order.

Physical proof before a cold team

  1. Print and trim: 5×3.5-inch cards, Letter maps, actual ticket sizes. Confirm both sides match. Count 22 cards. Check R1’s two tiny bolts and R6’s three boars without telling the tester the counts.
  2. Light puzzles: L2/L3 must reveal 1576 through the final stock. The mirrored ticket must reconstruct I–K while the stain still hides the original. The map’s reverse must not obscure the ticket signal. Test at ordinary table lighting.
  3. Aud route: walk every leg from the printed directions, separately recording bridge/ford/gate crossings. Check the alternate village branch. Make a marked operator answer image from the actual sheet; the existing ANSWER PDF shows the final seven, not the treasure-route solution.
  4. Weight: use the final scale and coin set. Repeat zeroing and weighing; verify the selected pile always gives the intended four retained digits and other piles do not. Match the cache and coin symbol; do not rely on knowing which pile the designer meant.
  5. Board: rebuild from the two papers with no help. Confirm exactly 16 dark, 6 light and one king. Check that all players follow the printed house rules and can count 2/5/3.
  6. Final shapes: hide ANSWER headings and expected digits. Ask someone unfamiliar with the game to identify the four north-up traced routes, then test incorrect routes including decoys. Record what they actually read. Do not prompt “does this look like a 2?”
  7. Hardware: test each combination, all needed letters and all closures. Check that both Rollo locks are necessary, the cryptex contains its key and no needed card is packed behind itself.

Cold playtest: one pair, then one group of four

Use people who have not read this page. Give only the opening materials and hint access. An observer may silently record problems, but should not supply missing rules; any intervention becomes a failed self-guided gate for that run.

Keep the visual identity

Forest green #283B34, paper #EFE3C4, muted rust #B56A2A. Trail accents: Leif blue, Rollo rust, Aud purple, Harald green. Vintage travel fronts; Liv’s handwriting for messages; typed Fun Facts and ticket furniture.

Make instructions easier to find

Give task/rule text breathing room. Keep the small family mark separate from rebus drawings. Keep stamp motifs and written place names useful without colour. A new player should distinguish a puzzle instruction from decorative history without reading designer notes.

Preserve the challenge

Explain operations when otherwise arbitrary: count movement not endpoints, move only the king, retain discarded-route cards, use grams, keep north up. The deduction is which data to combine, not guessing the designer’s unstated convention.

Type and physical usability

5×3.5-inch cards are compact for four people. Give one reader space to read aloud; use the larger journal proposal. Proof labels and credits at actual size. Magnification should support close-looking puzzles, not rescue all reading. Ensure final map marks can be wiped without damaging paper.
