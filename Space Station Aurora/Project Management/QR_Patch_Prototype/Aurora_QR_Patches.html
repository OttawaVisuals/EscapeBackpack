What this proves—and what still needs work

Software result: the bare code reaches the wrong URL; all 62 partial combinations are unreadable; the complete code reaches the correct URL. This covers correctly positioned tiles only, tested with jsQR 1.4.0.

Physical limitation: some connections are only one QR square wide. These outlines demonstrate coverage and decoding; they are not finished peg-board parts. They may need backing, stronger connectors or simpler shapes within the 50% limit.

Next check: print a flat prototype, then try the endpoints and all six “one tile missing” states with different phone cameras. Wrong positions, rotation, shadows and raised tile edges have not been validated.
