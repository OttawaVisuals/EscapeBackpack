Build your own QR patches.

Compare the base code with the target. Select a patch, then click or drag across squares to define its shape. Each selected square prints the target black or white value.

Starts with the same mask (3) for both codes: 58 changed squares. “Auto” can produce different masks and many more changes. Applying different settings clears existing patches after confirmation.

Click a square to begin. Coordinates start at row 0, column 0.
Keyboard and precise placement

Focus the grid and use arrow keys, then Space. Clicking a square already in the selected patch removes it. Assigning a square owned by another patch transfers it. Unchanged squares may be included to connect pieces.

2 · Up to six patches

The main coverage figure excludes the three corner markers and their white separators. “Parts” counts disconnected islands within a patch.

3 · Check the design

Tests all presence/absence combinations of defined patches, up to 64. This checks decoding, not incorrect placement or physical camera performance.

No combination test run for this layout.

4 · Save and export

ZIP includes one SVG per patch, separate cut outlines, base/target/assembled QR images, a placement diagram and the editable JSON. Print at 100%; QR artwork has no coloured borders. Disconnected patches export as separate islands within that patch’s SVG.

Export a layout file to keep a durable copy.
